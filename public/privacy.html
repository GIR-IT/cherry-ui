Privacy

Cherry (cherry-ui.com) and the Cherry for GitHub Chrome extension. Updated 8 October 2026.

Short version

Cherry collects nothing. There is no account, no analytics, no tracking and no Cherry server that sees your data.

The web app

  • cherry-ui.com is a static site. Everything runs in your browser.
  • If you add a GitHub token, it is stored in your browser's localStorage and sent only to api.github.com, to read repositories and to create the commits, branches and pull requests you ask for.
  • A few interface preferences (such as split or unified diffs) are also kept in localStorage.
  • Remove the token from the token dialog, or clear the site's data, to delete all of it.

The Chrome extension

  • On github.com it reads the page to place a Cherry-pick button and, on pull requests, to find the branch name. This stays on your device.
  • When you click the toolbar icon or press the shortcut, it reads the current tab's address (the activeTab permission) to open the matching cherry-ui.com page.
  • It sends no data anywhere, stores nothing and runs on no other site.
